# 多看 · 多直播监看工作台改造计划

## 目标与约定

将项目改造成 Linear 风格的深色监看工作台：关注列表管理房间，自由画布承载直播，声音、弹幕、画质和聚焦状态统一表达。保留现有取流、Cookie 登录、播放器和弹幕接入能力，重做外层界面、布局控制和状态管理，保留此前已有修改。

按下面顺序开发，每个阶段验证后更新本文。图标使用现有 Phosphor Icons，不使用 emoji。Windows BAT 的内容保持英文。

**当前范围：斗鱼、虎牙与直接直播流。** 按小马最新决定，B 站暂时隐藏并停止取流、信息刷新及弹幕连接，保存数据和底层适配代码保留；此前涉及 B 站的验收不再属于当前开发任务。

参考：
- [Linear UI redesign](https://linear.app/now/how-we-redesigned-the-linear-ui)：克制的表面、细边框、清晰层级。
- [ATEM Software Control](https://www.blackmagicdesign.com/products/atemmini/software)：视频优先、多画面操作和状态组织。
- 对比过 [Fluent 2](https://fluent2.microsoft.design/) 与 [The Swiss Grid](https://swissgrid.posterhouse.org/)，最终选择 Linear 深色工作台。

## 开发顺序

### 1. 斗鱼画质与房间信息

- 斗鱼 71415（寅子）为主要对照样本，核对同账号、同时间下 Dart 与本项目的画质列表、请求档位和实际返回档位。
- 计划阶段已验证：匿名接口列出“原画2K120”，请求 rate=0 后实际返回 rate=4（蓝光4M）。登录结果须另行验证。
- 使用接口提供的完整名称、rate、码率。每房间独立选择，默认最高可用档；有明确码率时按码率选择，否则遵循接口顺序。
- 对齐 Dart 的 Cookie、动态选档与签名刷新行为。先验证 V1；如同一有效 Cookie 下 V1 降档而 Dart 链路正确，采用 homeH5Enc 新签名与 getH5Play。签名脚本在有时间和内存限制的隔离 QuickJS 中计算。
- 展示实际档位，降档、账号限制、解码失败明确提示，切换失败保留原流。
- 获取斗鱼、B站、虎牙主播名、直播标题与头像，主播为主、标题为辅；头像失败回退平台图标，信息失败回退平台和房间号，不影响播放。直接流显示“自定义直播”。

### 2. 关注列表与观看会话

- 桌面左侧栏 264px，默认展开，可收起；窄屏为抽屉。
- 侧栏粘贴地址，Enter 提交，直接添加到当前布局；新添加的房间不自动关注。未开播和失败的临时房间也保留在当前布局，可刷新重试。
- 关注使用独立星标按钮，主动关注后才进入关注页；关注用于快速添加到布局。取消关注保留正在观看的画面，关闭画面保留关注。
- 成功开始播放后才记录历史，同平台真实房间号去重、最近观看排前，上限 50 条；可单条删除或清空。淘汰历史不关闭画面、不取消关注。
- 侧栏提供“关注 / 历史”页签。临时房间及普通布局随观看会话保存；关闭的未关注房间仅在有成功观看历史时保留。
- 可搜索主播、标题、平台和房间号，显示观看、声音、播放状态；重复打开定位已有画面。
- 同平台短号、别名与真实房间号归一化去重。
- 恢复上次观看房间和普通布局，静音启动；已关闭收藏不自动打开。
- 添加、整理全部、全部静音、清理临时房间、设置、分享在侧栏直接可达，收起后仍有工具入口。
- 收起侧栏去掉重复“+”；保留展开入口和开播关注数量，数量大于 0 才显示绿点，否则灰点。统计全部关注，不统计当前观看数量。页面可见时每 60 秒更新关注直播状态，最多 3 个并发请求；未知状态不计作开播。
- 移除顶部“正在观看”标题栏及重复的整理、静音、添加按钮，画布获得更多空间；手机保留浮动的侧栏打开入口。
- “清理临时房间”关闭布局内所有未关注房间，然后退出聚焦并整理剩余已打开画面；不自动打开未观看的关注，不删除历史、不取消关注，关闭时释放播放器和弹幕连接。

### 3. 统一外观

- 背景 #111214，面板 #191B1E / #22252A，边框 #34383F，文字 #E8EAED / #989FA9，强调 #8AABF5。
- 系统无衬线字体，中文回退微软雅黑；正文 14px、辅助 12px。4px 间距基础，画面圆角 8px、面板 12px。
- 常用图标 18px、统一线条，提供提示和可访问标签。
- 蓝色用于操作控件，2px 绿色边框表示“正在播放且声音已开启”；暂停为 2px 柔和红边，优先于声音绿边；其余灰边。移除普通选中状态与蓝色选中/聚焦描边，保留键盘控件焦点提示。
- 普通窗口和聚焦主窗口让视频铺满，上下控件覆盖画面，悬停、键盘操作、暂停或菜单打开时显示；聚焦缩略窗口闲置时保留淡主播名。触屏点画面显示控件。移除顶部独立声音按钮与“开声”标签，保留刷新直播、弹幕、关注、聚焦、更多、关闭。复制播放地址和打开原房间放次级菜单，菜单不再重复提供刷新与音量滑块。
- 采用统一简洁的自定义播放条，保留播放/暂停、静音、音量、全屏；流支持时显示缓冲与可回看范围、支持拖动和返回直播位置。普通画面点击不触发暂停。
- 画质与实际分辨率合并到播放条，移除独立画质栏。双击画面与右下角按钮切换同一种无边框房间全屏；全屏播放闲置 3 秒隐藏控件和鼠标，移动即恢复；暂停、菜单或正在操作时保持可见。全屏与聚焦互斥，共用自动开声偏好和声音恢复规则。
- 品牌统一“多看”；浏览器标题与图标、侧栏与空白页使用 Phosphor SquaresFour。空白主屏仅保留图标、YOUR LIVE DESK、把喜欢的直播，放在一起、添加第一个房间；标题到按钮间距 32px。
- 历史标题只显示“最近观看”，不显示数量上限；删除侧栏底部快捷键文字，说明统一放设置。
- 设置保留播放、弹幕、账号、帮助。通过 devIndicators:false 隐藏左下角 Next.js 开发入口 N。

### 4. 布局、声音与聚焦

- 单一自由画布，不再提供布局模式、行列数、格子合并设置。
- 未手调时，增删自动等大排列，不裁切；一个占满，两个宽画布左右、窄画布上下，三个以上按宽高最大化视频显示面积，最后不足行居中，可留空。整理全部结果稳定，不随点击次数轮换。
- 手调坐标尺寸持久化；新增优先空位，无空位新增约画布宽度 30%、16:9 浮窗，从右下错开放置，旧画面不变。
- 整理全部恢复自动排列；窗口和侧栏变化按比例适配。自由布局始终可用，拖标题移动、拖边缘/四角缩放；扩大拖动热区并在悬停时显示角标，聚焦期间暂时锁定普通布局。
- Alt+左键切换房间静音；Shift+左键播放/暂停；普通左键不改变播放状态。输入、播放条按钮、拖动、中键互不冲突。
- 声控与自定义播放条、底层视频音量同步；绿色声音边框不代表检测到了实际音频内容。
- 中键聚焦，主画面居中，约宽 70%、高 72%；其他先左右再上下，数量多时周边可滚动。
- 再中键同房间或 Esc 退出，中键另一房间切换；播放器保持挂载，保留缓冲。
- 临时解除静音；零音量用最近非零值或 50%。退出恢复进入前静音/音量，原本开声仍开声；期间主动调整优先。全部静音也算主动调整。其他房间不变。
- 聚焦不覆盖普通布局；增删更新普通布局记录。关闭焦点自动退出。

### 5. 自动弹幕

- 打开的支持平台房间自动连接，新房间默认开启，独立开关持久化。
- 限制在对应画面，以平台+真实房间号匹配，避免串房。
- 关闭清空弹幕并释放连接；重新开启重新连接；关闭房间/卸载清理所有资源。
- 失败独立提示，1、3、10 秒最多三次重试，随后手动重试；关闭取消重试。
- 保留间距、速度、不透明度并新增字号（12–40px）；默认字号 20px、不透明度 90%、间距 20px、速度 120px/s。设置显示预览、默认数据和恢复默认按钮；即时应用并持久化，不重连弹幕。旧手动源按房间迁移去重，新流程不用单独添加弹幕。
- 直接流没有弹幕来源时显示不支持。

### 6. 兼容、验证与文档

- 迁移旧房间、自由坐标、网格位置、分享链接；网格转自由矩形，保留旧存储作为恢复来源。此前自动加入的房间列表迁入历史，正在观看的继续留在布局；新存储区分临时、主动关注与成功观看历史。
- 新分享仅包含当前观看、普通布局、画质和弹幕偏好，不包含 Cookie；接收端静音，用自己的账号。
- 每阶段进行相关验证，最终更新 README 和本文件的验证结果。

## 接口与状态

- 斗鱼取流保留 stream 与旧 qn 兼容，增加精确 rate，返回 qualities、实际档位和降档说明。
- 统一房间信息接口返回归一化身份、主播、标题和直播状态；网络失败为未知，不能误报未开播。
- 区分关注、当前布局、最多 50 条观看历史与临时聚焦；画质、弹幕和普通布局持久化，连接和临时开声不持久化。
- Cookie 保存在当前浏览器，只用于本应用后端请求，不进入分享、文档、诊断日志。

## 验收

- 71415 与 Dart 对照：完整列表、精确 rate、有效/失效/无 Cookie、降档、切换失败、实际分辨率与源帧率、浏览器解码、超过 15 分钟播放与重新取流。
- 房间库：临时添加不自动关注、主动星标、头像、去重、搜索、关闭/取消关注互不误伤、成功播放历史、50 条淘汰、刷新恢复、离线失败记录、开播关注计数。
- 清理：全部未关注画面关闭并释放资源，历史不删、已关闭关注不自动打开，剩余画面自动排列，临时焦点关闭、已关注焦点退出时恢复声音。
- 布局：1/2/3/5/9 房间，侧栏与尺寸变化，拖动缩放，手调后新增，整理，聚焦增删切换；几何变化不重建播放器。
- 播放条与声音：普通点击不暂停，Shift 点按、播放按钮、Alt 点按、音量、绿色声音框、原本开声/静音、零音量、主动调整、全部静音、焦点切换退出、底层视频同步；缓冲回看与返回直播位置。
- 弹幕：三平台自动接入、独立开关、防串房、重试、清理；旧配置与旧分享恢复。
- TypeScript、生产构建、改动文件 lint；画质、音频恢复、几何与迁移行为测试；Edge 界面及交互检查。

## 已确定的默认值

Linear 深色；等大且比例舒服；中央焦点+周边缩略；手调后小浮窗；聚焦退出恢复且主动调整优先；临时布局/主动关注/50 条成功观看历史分开；左侧折叠栏，无顶部标题栏；绿色声音框；自定义播放条；一键清理临时房间后整理；恢复上次观看并静音启动。本地保存，不加入账号同步、开播通知或自动打开开播关注。

## 已确认的交互修订（2026-10-01）

本节与上文为当前实施依据，替代早期“添加即关注、取消关注同时关闭、蓝色选中框、顶部声音按钮、原生播放条”的方案。

1. 普通添加属于临时房间，保存到布局；独立星标才属于关注。
2. 成功播放进入历史，上限 50；历史是快速重开的入口。
3. 头像补入房间信息；收起栏删重复“+”，绿点数字表示正在直播的关注数。
4. 自由移动/任意缩放保留并改善操作提示；普通选中框删除，绿色边框仅表示已开启声音且正在播放。
5. Alt 点按声控、Shift 点按播放/暂停、中键聚焦；普通左键不会误触暂停。
6. 用户已选择自定义播放条；音量只保留在播放条，删除顶部声音按钮、“开声”文字及菜单重复滑块。
7. 删除顶部“正在观看”标题栏，工具统一到侧栏。
8. 清理临时房间：关闭布局中的未关注房间，退出聚焦，随后整理剩余画面；保留历史和关注。
9. 刷新直播提升到每个房间的标题栏，移除次级菜单中重复的刷新入口。
10. 修复动态类名被构建移除造成八方向缩放热区为零的问题；普通布局保持自由移动和任意缩放。
11. 视频铺满，标题与播放条覆盖显示；双击全屏，全屏闲置 3 秒隐藏鼠标与控件，菜单在全屏内仍可用。
12. 暂停红边优先于声音绿边，均为 2px；开播关注数为 0 时灰点；删除历史上限提示与侧栏底部说明。
13. 两房间宽屏左右、窄屏上下；反复整理保持同一结果。
14. B 站、虎牙独立取流，直连公开接口并设置超时、校验返回；B 站优先 H.264 并按请求格式选择，未开播明确提示。错误标注平台与房间，避免混淆并发请求。
15. 弹幕增加字号、预览、默认数据与恢复默认；名称统一“多看”，浏览器图标更新，空白页精简并留 32px 标题按钮间距。

## 本轮确认与修复顺序（2026-10-01）

以下规则替代早期分组、聚焦与全屏叠加、标题栏开声开关方案。先实施，再统一检查关注视图、排序和滑块开关。

1. **聚焦与全屏互斥，可直接切换。** 普通布局中键聚焦、双击或播放条按钮全屏；聚焦时双击转全屏，全屏时中键或聚焦按钮转聚焦。同一种模式再次触发或 Esc 返回普通布局。模式切换延续进入前的声音记录，不能把临时开声当成原始状态；退出恢复原静音与音量，期间主动调音或全部静音优先。其他房间不变，播放器保持挂载。
2. **自动开声只在全局设置提供滑块开关。** 聚焦／全屏共用一个持久化偏好，默认开启；直播窗口标题栏不放该开关。开启临时开声、零音量使用最近非零值或 50%，关闭则保持原声音。真全屏无边框、圆角、内边距。
3. **排序明确反馈。** 仅在“编辑排序”模式允许拖动；被拖房间半透明预览，原位置占位，目标显示插入标记。支持方向键排序，完成后保存；正常浏览不能误拖排序。
4. **取消直播中／未开播分组标题，使用两级排序。** 正常浏览先按直播状态（直播中、未开播、状态未知），再按统一保存的关注顺序；编辑时展示所有关注的纯手动顺序，允许跨状态拖动。编辑期间刷新只更新状态标记、不移动房间，完成后再按状态排列。新增关注追加末尾，直播状态变化不修改手动顺序。示例：保存 A、B、C、D，B、D 直播时显示 B、D、A、C；B 下播后显示 D、A、B、C。列表文字与头像绿色描边区分状态，未知不能误报未开播。
5. **聚焦布局临时锁定，缩略弹幕独立字号。** 聚焦期间不移动或缩放，退出恢复普通自由布局。全局弹幕设置新增“聚焦缩略窗口弹幕字号”滑块，范围 10–24px、默认 12px；主窗口和全屏使用普通字号。即时应用、持久化，恢复默认包括缩略字号。
6. **重新打开静音，音量持久化。** 保存每房间音量与最近非零音量，布局恢复时所有房间静音。临时聚焦、全屏和开声状态不写入会话；不新增记忆开声选项。
7. **历史默认头像视图，视图偏好分开保存。** 关注默认列表，历史默认头像，各自可切换且记住选择。头像角标明确表示“在布局中”，独立于直播绿色描边，可同时出现；头像菜单根据状态提供打开／关闭、刷新、关注／取消关注与删除历史。
8. **压缩普通列表并提供批量刷新。** 保留主播名、删除下方重复的直播标题，标题仍可在画面或悬停提示查看；侧栏底部新增“刷新所有房间”，刷新当前布局中的直播及关注房间状态，最多 3 个房间并发、重复点击受控，失败独立处理。

### B 站问题说明（已决定暂时隐藏）

- 小马提供的直播样本为 `https://live.bilibili.com/732`。取流接口 200 只证明获得地址，不能证明媒体可播放。

## 侧栏本轮调整（2026-10-01，功能已实现）

来源：桌面 `New 2.txt` 最新内容与小马随后补充。此前 8 项交互修复已完成，本节的 9 项功能也已实现；统一视图和临时列表排序规则替代此前独立视图、头像排序规则。最终验收结果见本节末尾。

### 已确认的选择

- 关注与历史共用视图偏好，新用户默认列表视图；视图切换按钮只在关注页显示。
- 收起侧栏显示正在直播的关注头像；点击打开与头像视图相同的图标菜单。
- “整理全部”参考当前自由窗口的大概位置，尽量保留左右、上下关系，不再直接按默认打开顺序重新分配画面。
- Ctrl + 左键点击直播画面刷新当前直播间，与标题栏刷新按钮使用同一行为。
- B 站暂时隐藏，停止加载。
- 按小马最后决定，聚焦时不禁用或置灰“整理全部”，它仍调整底层普通布局；聚焦期间只锁定手动移动与缩放，清理临时房间会先退出聚焦。

### 最终实施规则

1. **普通列表精简。** 关注列表保留星标和打开／关闭两个按钮；历史列表额外提供删除历史按钮。删除“更多”菜单及重复刷新入口。单间刷新保留在直播窗口标题栏，整体刷新保留在侧栏底部。
2. **头像菜单改为紧凑操作卡片。** 上方仅显示主播名、平台及直播状态；直播绿点、未开播灰点，状态未知明确区分。下方横排图标按钮，操作与普通列表一致。按钮仍有悬停提示、可访问名称、键盘导航与触屏热区；删除历史与常用操作适度分隔，避免误触。沿用 Phosphor Icons。
3. **统一视图偏好与旧数据迁移。** 共用一个偏好，首次默认列表；已有用户优先沿用原关注视图，历史跟随，不再保留两个互相独立的选择。关注页切换时历史同步更新。
4. **编辑排序临时用完整列表。** 无论平时是哪种视图，进入编辑后临时显示列表与纯手动顺序；完成后恢复原视图和状态优先排序，不写入临时列表选择。保留拖动反馈与键盘方向键，提供上下移动按钮供触屏操作；编辑时暂停视图切换。
5. **收起栏显示开播头像。** 仅显示正在直播的关注，沿用直播优先后的手动顺序；头像区域独立滚动，顶部开播计数与底部工具固定。零开播不显示绿点或占位头像；头像点击打开同款操作卡片，卡片位置限定在窗口内。
6. **新增关闭全部画面。** 侧栏底部提供“关闭全部画面”，只关闭当前布局，释放播放器和弹幕，退出聚焦／全屏，保留关注及成功观看历史。不整理空画布；与“清理临时房间并整理”使用不同图标并适度分隔，无画面时禁用。提供 8 秒撤销，恢复原布局并静音重新取流，不能恢复之前的播放缓存；开始新观看、改变关注或删除／清空历史时结束撤销。失败且尚无历史的临时房间也能在期限内撤销恢复。
7. **滚动与手机使用。** 当前关注和历史已有纵向滚动，历史数据仍最多 50 条；后续保持搜索、页签和底部工具固定。手机网页已有抽屉与基本按钮操作，桌面中键／Alt／Shift 对应功能通过按钮访问。已有 Edge 窄屏验证，不等同于真机 Safari／Android 验收；头像卡片、滚动和排序应纳入后续触屏检查。
8. **按现有位置整理全部。** 继续使用等大、比例舒服的自动格位，但按当前普通布局中各窗口的中心位置分配房间，尽量减小整体移动距离，保留大致左右、上下关系。采用全部窗口与全部格位的整体匹配，避免逐个就近占位把后续窗口挤到很远；距离按实际画布像素计算，重叠或距离相同使用稳定的次序处理。窗口尺寸统一，具体坐标不原样保留；连续整理保持稳定。两窗口手动交换左右后整理，交换关系应保留；宽屏左右、窄屏上下的既定规则继续适用。聚焦时参考其底层普通布局，不能把临时中央／缩略位置写入普通布局。“清理临时房间并整理”对剩余窗口沿用同一规则。
9. **Ctrl + 左键刷新当前直播间。** 仅在点击直播画面时触发，与标题栏刷新共用入口，刷新该房间的直播流与信息，保留当前布局、声音及播放／暂停状态。标题按钮、播放条、菜单、输入框和移动／缩放手柄保留各自操作，不触发该快捷键。刷新中重复点击受控；只有单独 Ctrl 修饰的左键触发刷新，多修饰键不叠加执行刷新、Alt 声控与 Shift 播放。Ctrl 双击不触发全屏。快捷键说明与本轮交互验收同步补充，检查正常布局、聚焦、全屏及控件操作。

位置整理实施时同时保存整理后的排列顺序，避免随后侧栏展开／收起、画布尺寸变化、刷新页面或新增房间，又被自动排列逻辑拉回原打开顺序。新增仍遵守既定规则：自由手调后保留现有矩形并插入小窗口；自动布局状态扩展格位时尽量保留现有排列关系。几何和顺序调整不能重建播放器或重新取流。验收包含左右交换、多行摆放、窗口重叠、连续整理、清理后整理、画布变化及保存恢复。
