# 本轮交互与卡流恢复约定（2026-10-01）

来源：小马本轮六项需求及后续确认。本文件优先于实施计划中成功播放才入历史、单击取消关注、侧栏直接分享等旧规则。先记录本文件，再开始代码修改。

## 后续交互（2026-10-02，已实施）

### 1. 修复聚焦小窗口的进度球

- 已确认原因：PlaybackControls 将所有非全屏的 is-thumbnail 窗口排除在进度球动画之外，但 CSS 只在窗口宽度不超过 280px 时隐藏进度条。因此，较宽的聚焦小窗显示了滑条，拖动预览更新，小球却不绘制。
- 统一真实显示条件：进度条可见时正常绘制，鼠标或触屏拖动时立即更新小球；确实隐藏、后台或全屏闲置时停止动画。
- 保留固定三分钟尺度、拖动冻结时间映射、只预览且松开寻址一次、过期范围检查；不为修复小球重复取流或改变回看缓存。

### 2. 明确当前键盘操作房间

- 全屏时控制全屏房间。
- 进入聚焦时默认控制主窗；明确点击某个小窗后控制该小窗，聚焦布局保持原样。
- 普通布局控制最后点击的窗口。鼠标经过只提示对应关系，不切换键盘目标。
- Tab 进入另一直播窗口的播放组件时，操作目标随之变为所属房间；在同一窗口内切换组件不改变方向键和空格的用途。
- 键盘目标与聚焦布局、开声策略、弹幕策略分别管理。点击确定操作目标不自动切换聚焦、开声、换画质或重建播放器。
- 目标关闭时清除失效引用；退出全屏／聚焦时回到仍存在的先前操作目标，普通布局没有有效目标时不猜测要控制的房间。

### 3. 统一房间级键盘操作

- 上／下：每次增减音量 5%，限制在 0～100%；提高音量时解除静音，降至零时静音，只作用于目标房间。
- 左／右：短按回退／前进 5 秒，只在真实可回看范围内移动。长按合并重复操作，采用累计预览后松开寻址，避免高频连续寻址造成卡顿。
- 空格：播放／暂停目标房间，与 Shift＋左键执行相同动作；聚焦和全屏也遵循同一目标规则。长按空格只切换一次，抑制随后原生按钮激活或页面滚动，避免双重触发。
- 焦点在画面、播放控制按钮、音量条或进度条上时，方向键与空格都由所属房间统一处理，不因误按 Tab 改变用途。鼠标拖动滑条继续有效；Enter 继续执行当前组件的原有操作。
- 搜索、地址输入、文本编辑、设置、菜单与排序期间保留组件自身键盘规则，暂停房间快捷键；修饰键组合和浏览器快捷操作不截获。
- 复用窗口内的短暂反馈显示音量、回看变化、播放／暂停，使用户看到实际受控窗口；不新增常驻面板。

### 4. 窗口与侧栏的悬停联动（以最新确认替代定位符方案）

- 移除独立定位符。鼠标经过直播窗口、列表项或头像时，对应的可见侧栏格子轻微提亮并显示淡淡的流光；收起侧栏的头像参与同样联动。
- 列表保留已确认的柔和浅灰蓝光泽及亮度，两片宽而淡的光泽在格子内流动，单程约 5 秒；增大位移范围并持续均匀流动，避免初段变化过小看起来静止。
- 头像视图及收起侧栏头像改为边框流光：柔和光泽沿现有 2px 边框连续流转，约 7 秒一周；头像内部不再覆盖流光。两种效果只在悬停时持续，离开后约 0.2 秒淡出，不再被本应用的减少动态样式切换成静态。
- 开播头像悬停或被对应窗口联动时，将静态绿色边框替换成绿色流光；未开播头像保留白色流光。两者使用相同速度和亮度，离开后开播头像恢复静态绿框。普通头像视图及收起侧栏共用该规则，右下角表示在布局中的绿灯保持不变。
- 列表与头像的进入、离开均约 0.2 秒平滑过渡：静态绿框、背景及头像提亮与流光同步交接。快速反复掠过时从当前亮度继续过渡；流光退出时暂停在当前相位并淡出，再进入时从该位置继续，隐藏时不持续运行动画。
- 流光只放在侧栏列表／头像对象中，不添加到直播窗口；头像的布局绿灯保持在流光上方。
- 鼠标经过侧栏对象时，对应直播窗口显示现有标题栏与底部播放栏，效果等同鼠标在该窗口内。聚焦小窗同样完整显示现有控件；窄小窗仍沿用自身尺寸适配，不强行塞入原本隐藏的进度条。
- 鼠标离开对象后恢复原有显示条件：普通播放恢复隐藏，暂停、菜单打开、键盘操作或鼠标仍在窗口内时遵循原规则；聚焦小窗保留原本常显的标题和名字。
- 悬停只提示对应关系，不改变键盘目标、聚焦、声音、弹幕或播放器，不自动打开房间、切换视图或滚动列表。目标被过滤／隐藏时不制造不存在的配对。
- 排序与拖动期间避免提示在对象间跳动，离开、取消、关闭房间或切换视图后正确清理。

### 5. 焦点提示是否冗余：分析与推荐

点击已经在内部确定键盘操作目标，聚焦主窗／全屏也已有明确的目标规则。如果再常驻定位符、增加键盘图标或新增一套焦点样式，会让同一窗口同时承担开声、暂停、在布局、悬停与焦点等多种标记，也需要用户理解多个相似定位符的区别。

采用临时的侧栏提亮和上下栏联动提示：点击复用当时的悬停效果，鼠标离开后恢复；键盘操作目标继续保留在内部，不新增常驻焦点符号。按快捷键时在实际目标窗口显示短暂结果反馈，兼顾确认目标与界面克制。

### 6. 仅增强列表视图的开播绿灯

- 当前列表开播状态使用 5px 的绿色圆点，配合状态文字；小马反馈绿色与灰色的区分不够明显。
- 推荐将列表开播绿灯略增至约 7px，沿用现有绿色系并适度提亮，增加很淡的静态柔光，让用户看向侧栏时容易辨认。
- 不使用循环呼吸、闪烁、跳动或明显扩散动画，避免多位主播同时开播时长期干扰余光。
- 只限定在列表项中的开播绿灯；未开播灰灯、头像视图、收起侧栏的头像／直播计数、头像菜单、窗口边框、文字与列表高亮均保留现状。绿灯表示主播正在直播，不表示该房间正在布局里播放。

## 关注防误触

- 未关注时单击星标直接关注；已关注时单击不取消，长按约 750ms 才取消关注。采用长按方案，替代此前分析中的二级菜单方案。
- 列表、头像操作菜单、直播画面标题栏共用该行为。长按开始显示红色星标减号图标，图标由下向上填充表示进度；提前松开、移出、指针取消、失焦或切到后台都中止并恢复原星标。
- 鼠标、触屏与键盘空格／回车都可操作，提示明确标注长按取消。一次长按只执行一次，不因随后的 click 再次关注，也不串到列表上移后的下一个房间。
- 取消后提供 8 秒撤销，恢复关注及原手动顺序；取消关注不关闭当前画面。与现有关闭全部撤销协调，后续改变关注、删除／清空历史或新观看结束旧撤销。

## 有效房间与历史

- 对启用的平台直播间，先通过平台信息接口确认真实房间存在，再立即记录历史，不以取得直播流或成功播放为条件。按平台与真实房间号去重。
- 已确认存在但未开播的新房间只进历史，不占画布，可在历史中关注；开播房间照常加入布局。重复添加不创建重复条目，也不因房间未开播关闭已有画面。
- URL 格式正确不等于房间存在。校验接口应检查真实房间身份，空对象、错误响应与无效 ID 不能视作存在。超时、网络故障显示暂时无法验证并允许重试，不能误报房间不存在。
- 原始直播流地址没有平台房间身份，继续在成功播放后记录。历史仍上限 50 条，关注不受历史淘汰影响；历史区域文案改为最近访问。

## 头像中键

- 关注、历史的头像视图，以及收起侧栏的开播头像，鼠标中键统一切换是否在布局中：未打开则加入，已打开则关闭并释放播放器／弹幕。
- 左键继续打开头像操作菜单。阻止中键自动滚动，同步布局角灯；画面中键仍执行聚焦，设置里的快捷操作分别说明。

## 设置、分享与项目链接

- 侧栏移除分享按钮，将复制当前布局链接放入设置；分享仍不包含 Cookie。
- 设置中只提供独立的本项目 GitHub 按钮，打开 <https://github.com/Masaicker/uni-live>。原仓库 <https://github.com/qianjiachun/uni-live> 的来源声明放在 README，不放入设置按钮区域。
- 聚焦／全屏自动开声默认开启，沿用现有共用偏好；已有用户主动关闭的保存值仍有效。

## 整理快捷键

- 焦点位于布局区域时，按 R 等同于点击整理全部，调用同一个整理入口，包含聚焦模式下对普通布局的整理。
- 点击布局区域可获得键盘焦点；输入框、可编辑内容、菜单和设置中的 R 不触发整理，组合键及按住重复不触发。设置快捷操作与 README 补充说明。
- 布局容器保留键盘焦点但不显示蓝色外框，按 R 后也不描边；按钮和输入框的键盘焦点提示继续保留。

## 卡流自动恢复

- 默认关闭，设置提供开关、卡流判定时间、基础重试间隔及最多重试次数，偏好保存在本浏览器。
- 默认参数：连续停止推进 20 秒判定卡流，基础重试间隔 30 秒，最多连续尝试 3 次；后续失败间隔逐步拉长。达到上限停止自动恢复，保留手动重试，手动重试开始新的恢复周期。
- 正常持续播放不触发自动刷新，不按固定周期刷新全部直播。只监控曾经正常播放的房间，结合媒体时间／解码帧推进、连接错误检测；恢复后需持续正常推进才清零失败计数，不能只因 onPlay 事件重置。
- 主动暂停、回看拖动、换画质／正在刷新、浏览器离线或后台页面不触发。恢复前台、恢复网络或结束上述操作后重新给予完整观察时间，避免立即误判。
- 每次恢复只刷新目标房间；先确认平台状态，明确下播则停止重连，状态查询失败不能误当下播。保留布局、声音、暂停和画质偏好；重取流可能重置回看缓存。
- 关闭房间、关闭全部或关闭自动恢复时中止未完成的自动恢复。防止同一房间重复请求；旧播放器和已关闭房间的回调不得触发刷新。
- 持续发送同一静止画面但时间／解码仍推进的直播源，无法可靠判断是否卡住，不承诺识别所有静止画面。
