# 多看

把喜欢的直播，放在一起。基于 [qianjiachun/uni-live](https://github.com/qianjiachun/uni-live) 改造的多平台直播工作台。

本 Fork：[Masaicker/uni-live](https://github.com/Masaicker/uni-live)。采用统一深色界面、自由画布与关注列表，保留并改进原项目的取流、播放器和弹幕能力。

### 功能

- 支持斗鱼、虎牙直播间，以及直接输入直播流地址。B 站暂时隐藏：输入地址会提示暂不支持，已保存的房间数据保留，但不展示、不自动播放或刷新。
- 统一自由画布：拖动标题移动，拖动四边或四角缩放。整理全部根据窗口当前位置恢复等大排列，尽量保留左右和上下关系；两个房间宽屏左右、窄屏上下。整理顺序随布局保存，手调后新增不会覆盖已有位置。
- 平台地址先确认真实房间存在，立即进入最近访问历史；未开播只保存到历史，不占画布，开播后照常加入布局。真实房间号去重，可在历史中直接关注。原始直播流地址成功播放后记录。
- 关注和历史共用列表／头像视图，首次默认列表，切换按钮放在关注页；沿用已有关注视图选择。收起栏显示开播关注头像，点击打开同款图标菜单；头像外圈绿色描边表示开播，右下角发光绿灯表示已在布局中。列表保留主播名，状态独占下一行，直播标题在画面或悬停提示查看。
- 关注平时按直播状态优先、再按手动顺序排列；点击“编辑排序”临时用列表展示完整手动顺序，支持拖动预览、插入标记、方向键与上下移动按钮。完成后恢复原视图，状态刷新不改变手动顺序，编辑期间不跳位。
- 普通关注列表保留星标和打开／关闭按钮，历史额外提供删除记录；头像菜单使用同样的图标操作。未关注时单击星标关注，已关注时长按 0.75 秒取消；红色星标减号由下向上填充，提前松开或移出中止，取消后有 8 秒撤销并恢复排序。列表、头像菜单和画面标题栏统一行为。关注、历史和收起栏头像均可滚动，底部工具保持可用。
- 关注／历史头像和收起侧栏头像支持中键：未在布局中则打开，已在布局中则关闭。左键仍打开操作菜单。
- 中键聚焦，中央大画面与周边缩略窗口同时保留；全屏与聚焦互斥，可直接切换，播放器保持挂载。设置中的“聚焦／全屏时自动开声”滑块共用一个偏好，退出恢复原声音；期间主动调整的声音保留。
- 半透明标题与自定义播放条覆盖画面，悬停或操作时显示。绿色边框表示正在播放且声音开启，红色边框表示暂停。
- 每个房间自动连接弹幕，独立开关；设置提供字号、间距、速度、不透明度、预览和恢复默认。聚焦缩略窗口字号单独设置，默认 12px。
- 斗鱼使用登录 Cookie 和动态画质档位，显示实际返回画质；切换失败保留原画面。
- 支持流提供的缓冲回看范围；范围由播放器实际缓存决定。刷新会重新取流，缓存可能重置。
- 布局、关注、历史与偏好保存在本浏览器；重新打开静音启动。设置的“项目”页可复制当前布局分享链接，不包含 Cookie；独立 GitHub 按钮打开本 Fork。
- 关注状态每 60 秒刷新，隐藏页面暂停刷新，回到页面时更新。侧栏底部“刷新所有房间”刷新当前布局的直播及关注状态，批量最多 3 个房间并发。
- 卡流自动恢复默认关闭，设置中可开启并调整判定时间、基础重试间隔和最多连续重试次数，默认 20 秒／30 秒／3 次。只监控曾正常播放的房间，持续播放不定时刷新；主动暂停、回看拖动、后台或离线时暂停检测。连续失败间隔逐步拉长，到上限停止，手动刷新可重新尝试；明确下播停止重连，稳定播放后清零计数。重新取流可能重置回看缓存，持续输出相同静止画面的源不保证能识别。
- 侧栏底部“关闭全部画面”释放当前播放器和弹幕、退出聚焦／全屏，保留关注及访问历史，并提供 8 秒撤销。撤销恢复布局并静音重新加载；开始新观看、改变关注或删除／清空历史会结束撤销。

### 快捷操作

| 操作 | 功能 |
| --- | --- |
| Alt + 左键点画面 | 开启或关闭该房间声音 |
| Shift + 左键点画面 | 播放或暂停该房间 |
| Ctrl + 左键点画面 | 刷新当前直播与房间信息，保持声音、暂停状态和布局 |
| 双击画面 / 播放条全屏按钮 | 进入或退出该房间全屏 |
| 鼠标中键 / 标题栏聚焦按钮 | 聚焦房间，全屏时直接转聚焦；开声遵循设置 |
| 再次中键 / Esc | 退出聚焦，恢复普通布局 |
| 中键点侧栏头像 | 添加到布局，或关闭已有画面 |
| R（焦点在布局区域） | 整理全部；输入框、菜单和设置不触发 |
| 长按星标 0.75 秒 | 取消关注，提前松开中止，完成后可撤销 |
| 拖动标题 / 四边与四角 | 移动 / 缩放，聚焦与全屏期间锁定布局 |

普通左键点画面不会暂停；普通布局点按窗口会将它置顶，保留位置、大小及自动排列方式。列表和头像菜单使用播放／停止图标打开／关闭画面，关闭不会取消关注。全屏播放时闲置 3 秒隐藏鼠标与控件，移动即恢复；暂停、菜单打开和操作期间保持可见。
聚焦与全屏切换延续进入前的声音记录；退出任一模式回到普通布局。全屏占满浏览器屏幕，不留边框或内边距。
聚焦期间移动和缩放锁定，“整理全部”仍可调整保存的普通布局。Ctrl 快捷键仅作用于直播画面，按钮、菜单和拖动手柄执行自身操作；刷新中重复点击受控。

### 本地运行（Windows，无需 Docker）

安装 Node.js 22 LTS，然后双击项目根目录的 `start.bat`。
脚本仅在缺少依赖时安装；首次、构建缺失或源码／配置变化时自动构建生产版本，未变化则直接启动。通过内容指纹判断，新增／删除文件也能识别。页面无需打开后再等待开发编译。脚本及提示使用英文，避免编码问题。

默认访问 `http://localhost:3000`，手机可使用电脑的局域网 IP 加 `:3000`。运行时保留终端窗口，按 `Ctrl+C` 停止服务；端口被占用时先停止占用它的服务，或设置 `PORT` 为其他端口。相同浏览器与访问地址可以沿用已有布局、关注及 Cookie，换端口或域名则使用独立的浏览器存储。

更新源码后，先停止生产服务，再运行 `start.bat`，会自动判断是否重建。也可强制重建并启动：

```powershell
.\start.bat --rebuild
```

若只需要构建、不启动，运行 `build.bat`。生产模式只在需要时生成运行产物；开发模式持续编译并热更新，两者不同。

依赖文件有更新时，先执行 `npm.cmd ci --cache ".cache\npm" --no-audit --no-fund`，再运行上述重建命令。生产构建放在 `.cache/production`，与开发目录分开；不要同时运行两个使用该生产目录的构建或服务。

修改代码时使用 `dev.bat`，或执行 `npm.cmd run dev -- --port 3001`。开发服务固定使用 `http://localhost:3001`，会按需编译和自动更新页面；生产服务使用 `3000`，二者构建目录独立。终端中的 `▲ Next.js 15.5.20` 表示所用框架及版本，不代表重新安装。两种地址的浏览器数据仍分别保存，切换端口不会自动搬运关注和布局。

### 斗鱼登录

网页设置的“账号”页点击“打开浏览器登录斗鱼”。Windows 本机安装 Microsoft Edge 时，项目打开独立 Edge 窗口；在官方页面登录后自动获取 Cookie 并关闭窗口，无需安装插件。

也可粘贴完整 Cookie，支持 Cookie 值或带 `Cookie:` 的请求头。远程部署与 Docker 使用粘贴方式。

Cookie 保存在当前浏览器，取流时发送给本应用后端，仅用于斗鱼签名和播放请求，不进入分享链接。登录、保存或清除后，已打开的斗鱼房间自动重新取流。

已启用平台的公开取流请求均设置超时并直连平台，不使用本机 `HTTP_PROXY` / `HTTPS_PROXY`。网页取流接口、实际媒体与弹幕连接分别运行在后端与浏览器，故障也分别处理。平台可能限制未登录账号的画质；“2K120”是源档位名称，不等于浏览器已验证达到 120 帧。

### Docker 部署（可选）

镜像内置 Node 20，不依赖宿主机 Node 版本。

```bash
git clone https://github.com/Masaicker/uni-live.git
cd uni-live
docker build -t duokan-live .
docker run -d --name duokan-live --restart unless-stopped -p 7002:7002 duokan-live
```

若已安装 Docker Compose：

```bash
docker-compose up -d --build
```

更新已有 Compose 部署可执行 `docker-compose up -d --build`。
访问 `http://服务器IP:7002`；反向代理指向 `http://127.0.0.1:7002`。
