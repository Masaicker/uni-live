# 多看

**把喜欢的直播，放在一起。** 支持斗鱼和自定义直播流的多窗口直播工作台。

## 功能

- **多路同看**：自由拖动、缩放和整理窗口，支持聚焦与全屏。
- **关注与历史**：列表或头像视图，显示开播状态，支持手动排序。
- **独立控制**：每个房间可单独选择画质、调整声音和开关弹幕。
- **三分钟回看**：支持暂停、回看和返回直播；范围以实际缓存为准，刷新或换画质会清空缓存。
- **保存与分享**：布局、关注和偏好保存在当前浏览器；可分享布局，链接不含登录 Cookie。
- **卡流恢复**：可在设置中开启自动重试。

B 站和虎牙暂不支持。

## 快速开始

### Windows

1. 安装 [Node.js 22 LTS](https://nodejs.org/)。
2. 下载项目，双击根目录的 `start.bat`。
3. 打开 **[localhost:3000](http://localhost:3000)**。

首次启动会安装依赖并构建。运行时保留终端窗口，按 `Ctrl+C` 停止服务。

更新源码后，先停止服务，再运行 `start.bat`，会自动判断是否重新构建。依赖有更新时先执行 `npm.cmd ci`。

| 脚本 | 用途 |
| --- | --- |
| `start.bat` | 启动生产版本 |
| `start.bat --rebuild` | 强制重新构建并启动 |
| `build.bat` | 只构建，不启动 |
| `dev.bat` | 开发模式，端口 `3001` |

### Docker

在项目目录运行：

```bash
docker compose up -d --build
```

访问 `http://服务器IP:7002`。更新源码后执行同一命令即可重新构建部署。

## 常用操作

输入直播间地址添加画面；拖动标题移动窗口，拖动边缘或角落缩放。

| 操作 | 功能 |
| --- | --- |
| `Alt` + 左键点画面 | 开关声音 |
| `Shift` + 左键点画面 | 播放／暂停 |
| `Ctrl` + 左键点画面 | 刷新直播间 |
| 鼠标中键 | 进入／退出聚焦 |
| 双击画面 | 进入／退出全屏 |
| `↑` / `↓` | 音量增加／降低 5% |
| `←` / `→` | 回退／前进 5 秒 |
| `空格` | 播放／暂停 |
| `R` | 整理窗口 |
| `Esc` | 退出聚焦／全屏 |

方向键和空格控制当前选中的房间，适用于普通布局、聚焦和全屏；输入框、菜单与设置保留自身按键。

## 斗鱼登录

进入 **设置 → 账号 → 斗鱼**：

- **本机运行**：点击“打开浏览器登录斗鱼”，在独立的 Chrome 或 Edge 窗口登录后自动保存 Cookie。
- **Docker／远程部署**：粘贴斗鱼 Cookie，点击“检测并保存”。

可用画质以平台返回为准，高画质可能需要有效登录。布局和登录信息按浏览器及访问地址分别保存。
